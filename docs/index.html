How it works

  • Drag an element within its line, into another line, or off the screen to park it.
  • Drag a line by its ⠿ handle or by empty space in it.
  • Drag a block by its title. Blocks go in the sidebar or the band above the prompt.
  • × parks an item. In Parked, × deletes it for good.
  • Double-click an element to edit its text.
  • Del parks the selection. Alt+arrows nudge it. Esc clears.
  • A red dashed outline marks a data element that will not be drawn where it sits: its data belongs to another part of the screen.
  • The transcript, the "Churned for" line, the prompt and the mode line are drawn by Claude Code and stay fixed.
